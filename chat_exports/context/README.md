# Папка для файлів контексту

Ця папка містить файли контексту, які допомагають передавати інформацію між різними AI сесіями (Cloud Agent ↔ локальний Cursor).

## 📝 Як використовувати

### Створити новий контекст:

**Linux/macOS:**
```bash
./save_context.sh "Описування що робили"
```

**Windows:**
```cmd
save_context.bat "Описування що робили"
```

### Продовжити з контексту:

1. Стягніть зміни: `git pull`
2. Відкрийте новий чат в Cursor
3. Напишіть:
   ```
   Привіт! Прочитай @chat_exports/context/context_YYYY-MM-DD_HHMMSS.md 
   і продовж роботу звідти
   ```

## 📋 Формат файлів

Файли називаються: `context_YYYY-MM-DD_HHMMSS.md`

Приклад: `context_2026-09-18_115000.md`

## 🔍 Знайти останній контекст

**Linux/macOS:**
```bash
ls -lt chat_exports/context/ | head -5
```

**Windows:**
```cmd
dir /o-d chat_exports\context\ | findstr /v "Папка директория"
```

## 🗑️ Очищення старих файлів

Якщо файлів багато, можна видалити старі:

**Залишити тільки останні 10:**
```bash
cd chat_exports/context/
ls -t | tail -n +11 | xargs rm --
```

## 💡 Порада

Додавайте детальні нотатки в секції "What to do next" та "Important notes" кожного файлу контексту - це найважливіша інформація для продовження роботи!
