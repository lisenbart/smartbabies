# 💬 Історія розмов з Cursor AI

Цей каталог містить історію важливих розмов з Cursor AI.

## 📁 Структура

- `conversations/` - експортовані розмови в Markdown форматі
- `backups/` - повні бекапи даних Cursor (локально, не в git)

## 🔄 Як додати нову розмову

### Метод 1: Ручний експорт (рекомендовано для важливих розмов)

1. Відкрийте чат у Cursor на Windows
2. Виділіть весь текст (Ctrl+A, Ctrl+C)
3. Створіть новий файл тут:
   ```
   conversations/YYYY-MM-DD-назва-теми.md
   ```
4. Вставте текст та відформатуйте при потребі
5. Закомітьте:
   ```bash
   git add chat_exports/conversations/
   git commit -m "Add chat: назва теми"
   git push
   ```

### Метод 2: Через бекап файли

1. На Windows запустіть `cursor_chat_backup_windows.bat`
2. Скопіюйте створену папку бекапу в `chat_exports/backups/`
3. Додайте в git (якщо розмір дозволяє)

### Метод 3: Через Cloud Agent

Якщо ви працюєте в Cloud Agent, просто створіть файл з історією розмови прямо тут.

## 📝 Формат імені файлу

Використовуйте формат:
```
YYYY-MM-DD-короткий-опис-теми.md
```

Приклади:
- `2024-01-15-project-setup.md`
- `2024-01-16-bug-fixes-authentication.md`
- `2024-01-17-feature-user-dashboard.md`

## 🔍 Як знайти розмову

Використовуйте git для пошуку:

```bash
# Пошук по тексту
git grep "ключове слово" chat_exports/

# Список всіх розмов
ls -lt chat_exports/conversations/
```

## 💾 Розмір файлів

- Текстові експорти: зазвичай < 100 KB
- Повні бекапи: можуть бути > 10 MB

**Порада:** Зберігайте в git тільки текстові експорти важливих розмов. Повні бекапи краще тримати локально або в хмарі.

## 🚫 .gitignore

Великі файли виключені через `.gitignore`:
- `*.db` - бази даних SQLite
- `*.db-shm`, `*.db-wal` - тимчасові файли SQLite
- Файли розміром > 10 MB
