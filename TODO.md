## 💡 Важливі нотатки (Important Notes)

### Технічні рішення
- **Хостинг:** GitHub Pages (smartbabies проект)
- **Синхронізація:** Git як шина даних між Cloud Agent і локальним Cursor
- **Бекапи:** Локальні через cursor_chat_backup.sh та .bat скрипти

### Інструменти синхронізації
- `save_context.sh` - для Linux/macOS/Cloud Agent
- `save_context.bat` - для Windows
- `TODO.md` - центральний файл стану проекту
- `chat_exports/context/` - файли контексту для передачі між сесіями

### Структура проекту
```
/workspace/
  ├── chat_exports/          # Експорт розмов та контексту
  │   ├── conversations/     # Збережені розмови
  │   ├── context/          # Файли контексту для синхронізації
  │   └── backups/          # Повні бекапи (локально, не в git)
  ├── save_context.sh       # Скрипт збереження контексту (Unix)
  ├── save_context.bat      # Скрипт збереження контексту (Windows)
  ├── TODO.md               # Поточний стан проекту
  ├── QUICKSTART_SYNC.md    # Швидкий старт синхронізації
  └── CURSOR_CHAT_BACKUP_GUIDE*.md  # Інструкції бекапу
```

## 🐛 Відомі проблеми (Known Issues)

1. **Tree команда не встановлена**
   - Опис: save_context.sh показує помилку "tree: command not found"
   - Файл: `save_context.sh`
   - Рішення: Не критично, використовується fallback до `ls -la`
   - Можна встановити: `apt-get install tree` (якщо потрібно)
